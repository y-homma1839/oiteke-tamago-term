トップ 利用規約

本プライバシーポリシー（以下「本ポリシー」）は、モバイルアプリケーション「おいてけ！たまご」（以下「本アプリ」）におけるユーザー情報の取扱いを定めるものです。本アプリは、ユーザーが選択したアプリを一定時間制限しながら卵を孵化させ、生き物を図鑑に集めるエンターテインメントアプリです。本アプリをダウンロード、インストール、または利用した時点で、本ポリシーに同意したものとみなします。

1. 運営者・お問い合わせ

本アプリの運営者（以下「運営者」）へのお問い合わせは、次のメールアドレスまでご連絡ください。

yoshiki.apps.support@gmail.com

2. 本アプリの特徴とデータの扱いの基本方針

  • 本アプリは運営者独自の会員登録・ログイン機能を持ちません。
  • ゲーム進行データ（卵・孵化・図鑑・コイン・ロック設定等）は、原則としてユーザーの端末内に保存されます。
  • 運営者がユーザーの氏名・住所・電話番号等を必須で収集することはありません。
  • 広告・課金・アプリ制限機能のため、OS および第三者 SDK が端末・広告・購入に関する情報を処理することがあります。

3. 収集・利用する情報

3.1 端末内のゲームデータ（運営者サーバーへ送信しません）

次の情報を、端末内のローカルデータベース等に保存します。

  • コイン残高およびコインの増減履歴
  • 選択中・過去の卵、孵化の進行状況、獲得した生き物、図鑑の開放・レベル状況
  • ロックするアプリの選択内容（Android ではパッケージ名等、iOS では Screen Time / Family Controls により選択されたアプリ・カテゴリ情報）
  • ロックセッションの開始時刻・継続時間・有効／無効の状態
  • プライバシーポリシー／利用規約への同意状態
  • 広告なしプラン等の特典状態（端末上のフラグ。購入の正はストア／RevenueCat 側）
  • 課金まわりで用いる匿名の端末ユーザー識別子（ストア連携用）

これらのデータは、本アプリの機能提供のために端末上で利用されます。運営者が管理する独自サーバーへアップロードする仕組みは、現時点では設けていません。

3.2 アプリ制限機能に伴う端末上の情報・権限

本アプリの中核機能として、ユーザーが選んだアプリをロックセッション中に制限します。このために、OS の仕組みおよび次の権限・機能を利用することがあります。

  • Android：使用状況へのアクセス、他のアプリの上に表示（オーバーレイ）、通知、フォアグラウンドサービス等。制限対象としてユーザーが選んだアプリの情報を端末内に保持し、ロック中のみ監視・制限に用います。
  • iOS：Screen Time / Family Controls（ファミリーコントロール）関連の許可。ユーザーがピッカーで選んだアプリ・カテゴリの選択データを端末／アプリグループ内で保持し、ロック中の制限に用います。

権限を拒否した場合、ロック機能の全部または一部が利用できません。ゲームの閲覧・図鑑等の一部機能は権限なしでも利用できる場合があります。

3.3 広告関連情報

無料利用時、第三者の広告（Google AdMob 等）を表示することがあります。広告配信・計測・不正防止のため、次の情報が広告事業者等により収集・処理される場合があります。

  • 広告識別子（Advertising ID / IDFA 等。OS の設定およびユーザーの許可状況に依存）
  • 端末情報、IP アドレス、ネットワーク情報、アプリ・広告の表示／操作に関する情報
  • 同意管理（UMP 等）に基づく同意状態（主に規制対象地域）

iOS では、トラッキング許可を求める場合があり、その目的は広告の配信状況の計測および関連性の高い広告の表示です。許可しなくても本アプリの基本機能は利用できますが、広告の内容や表示に影響する場合があります。

3.4 課金・サブスクリプション関連情報

コイン購入および広告なし等のサブスクリプションは、Apple App Store / Google Play および RevenueCat を通じて処理されます。運営者がクレジットカード番号等の決済情報を直接保持することはありません。購入履歴、購読状態、匿名化されたユーザー識別子等が、各事業者により処理されます。

3.5 通信・診断情報

広告・課金・文書表示（プライバシーポリシー等の Web 表示）のため、インターネット接続を利用します。OS や SDK の仕様により、クラッシュや性能に関する情報が処理される場合があります。

3.6 お問い合わせ時に任意で提供される情報

ユーザーがメールで問い合わせる際、メールアドレスおよび本文に記載した情報が運営者に届きます。対応に必要な範囲で利用し、不要になり次第、合理的な期間内に削除または保管を終了します（法令上の保管義務がある場合を除く）。

4. 利用目的

  • 卵の孵化、図鑑、コイン、ロック等、本アプリの機能の提供・維持・改善
  • ユーザーが選択したアプリの制限（ロックセッション中）
  • 広告の配信、計測、不正防止、同意管理
  • アプリ内課金・サブスクリプションの提供、購入状態の確認・復元
  • お問い合わせ対応
  • 利用規約違反への対応、および法令に基づく対応

5. 第三者への提供・第三者サービス

運営者は、法令に基づく場合等を除き、ユーザーを特定できる情報を第三者に販売しません。一方、本アプリの動作のため次の第三者サービスを利用し、各サービスの範囲で情報が処理されます。

  • Google AdMob（広告）
  • RevenueCat（アプリ内課金・購読管理）
  • Apple App Store / Google Play（配信・課金）
  • GitHub Pages 等（本ポリシー／利用規約の公開・アプリ内表示のための取得）

各事業者の取扱いは、それぞれのプライバシーポリシーおよび利用規約に従います。

6. 保存場所・保存期間

  • 端末内ゲームデータ：本アプリをアンインストールするまで、またはユーザーが端末上でデータを消去するまで。
  • 第三者サービス側のデータ：各サービスの定めに従います。
  • お問い合わせメール：対応に必要な期間。

7. データの削除・管理方法

  • 端末内データは、本アプリのアンインストールにより削除されます（OS のバックアップ等により端末側に残る場合を除く）。
  • 課金・購読の解約・管理は、Apple / Google のアカウント設定から行ってください。
  • 広告識別子やパーソナライズ広告の設定は、端末の設定および（表示される場合）アプリ内の広告プライバシー設定から変更できることがあります。
  • ロック対象アプリの選択内容は、本アプリ内の設定画面から変更できます。ロックを終了すると、制限は解除されます。

8. 子どもの利用

本アプリは、子ども向けに特化して設計されたアプリではありません。保護者の方は、お子さまの端末利用、スクリーンタイム／家族向け設定、ストアアカウント、課金・広告の設定をご確認のうえ、必要に応じて監督してください。

9. 安全管理

運営者は、取り扱う情報の漏えい等を防ぐため、取り扱う範囲および手段に応じた合理的な安全管理に努めます。ただし、インターネットおよび端末環境の性質上、絶対的な安全を保証するものではありません。

10. 国外への転送

広告・課金等の第三者サービスは、日本国外でデータを処理する場合があります。各サービスのポリシーに従って処理されます。

11. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを改定できます。重要な変更がある場合は、本ページの更新日を改定し、アプリ内または本ページ上で周知します。変更後に本アプリを利用した場合、改定後の本ポリシーに同意したものとみなします。

12. 準拠法

本ポリシーは日本法に準拠し、解釈されるものとします。
